## 剧情 / 对话界面重做（storyui）

**目标**：按苹果 HIG 重做剧情播放界面，让字幕更安静、更好读，不抢画面。

**做了什么 / 规则**
- 底部居中的毛玻璃字幕卡（`--mat-regular` + blur，圆角 22）：左侧 56pt 圆形头像，名牌 13/600 次级色，正文 17/22 主文字色。
- 逐字显示：已显示的字 + 不可见的剩余字（`.story-ghost`），整句的换行位置一开始就定好，卡片高度不会边打边跳；点一下直接显示整句，再点才推进（沿用原逻辑）。
- 右下角 12px 小三角"继续"提示，呼吸动画；设置里的"减少动态效果"（`calm` 类）和系统偏好都会关掉动画。
- 换人说话时头像淡入 + 微弹（0.36s）。
- "跳过"：右上角 32pt 毛玻璃胶囊，点击热区用 `::after` 扩到 44pt 以上。章节标题改成顶部小胶囊。
- 旁白（说话人为空 / `null` / `'narrator'`）：不带头像、居中 20/32 大字；舞台上的人物都暗下去。目前剧情数据里**还没有**旁白句，这是预留的数据格式。
- 底部细进度圆点（当前句是长条，已读句较亮）。
- `text-wrap: pretty` 防孤字；`overflow-wrap: anywhere` 防英文长词溢出。
- 纯逻辑抽到 `src/ui/storytext.js`（旁白判断、按字符切片避免劈开 emoji、标点停顿节奏）。`introPaused`、跳过、已读记录的代码未改。
- 新文件：`css/storyui.css`、`src/ui/storytext.js`、`tests/feat-storyui.test.js`；`index.html` 各加一行。没有新增文字，`i18n-add/storyui.json` 为空对象。

**验证了什么**：`node --test`（见测试结果）；Playwright 对 pre60 在中文 / 英文、桌面 1280x720 / 横屏手机 844x390 各截 3 帧 + 一段旁白，无控制台报错。

**没验证什么**：真机触控；手机竖屏（游戏本身会整体旋转 / 缩放，热区实际大小随缩放变化）；`intro` / `diary` / `ending` 界面没有改（只截图看了现状）；旁白只用临时构造的数据测过；大字号设置下的版式只看了 CSS 没截图。
