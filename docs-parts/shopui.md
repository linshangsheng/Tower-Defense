## 商店 / 配装各页布局规范化（shopui）

**目标**：按苹果 HIG 统一商店各页签：页头、说明文字、卡片、锁定状态、装备分类控件、滚动区。只改结构与样式，购买 / 升级逻辑不变。

**规则**
- 页头 `pageHead(title, sub, action, tip)`：大标题 24/700 + 一行 13 号次级色副标题 + 右侧可选主操作（配装页的"一键推荐配装"、道具页的"栏位 x / y"pill）。页头 `position: sticky`，底下 8px 渐隐遮罩；滚动区仍是 `.shop-content`。
- 长说明改成折叠小提示：页头下一行"怎么用？"（灯泡图标 + 箭头，`aria-expanded`），默认折叠，点开在页头下展开原有说明句（技能 / 道具 / 兵营 / 装备页）。开合状态存在 `UI.shopTips`，同一次游戏内换页签再回来保持。
- 卡片：同页网格 `align-items: stretch` 等高，竖版卡片按钮 `margin-top: auto` 贴底，横版卡片右侧按钮列固定 164px；等级为 pill，价格在按钮里做成 pill。`buyBtn` 钱不够时按钮仍灰，下面多一行"还差 [币]N"（纯函数 `TD.shopui.shortage`，与 `canAfford` 一致）。
- 锁定：`lockNote(text)` = 线性锁图标 + 一行解锁条件，用于终极技能未解锁、兵营兵种未解锁、道具栏位未开。
- 装备页：七个分类和品质筛选改成 iOS 分段控件（灰色轨道 + 白色滑块），分类计数只在选中项显示以免挤出屏幕。
- 小节标题去掉金色菱形和长线，改为 13 号次级色文字。
- 新文件：`src/ui/shopui-core.js`（纯函数，已登记 `index.html` 与 `tools/load.js`）、`css/shopui.css`。兵营页只改页头与外层，卡片内部未动（仅"未解锁"右侧用了 `lockNote`，样式由 CSS 控制）。

**各页做了什么**：配装（页头 + 推荐按钮移入页头）；属性 / 城墙 / 汇兑（页头，去掉原金色标题行）；技能（页头 + 三条说明折叠）；装备（页头 + 武器 / 装备说明折叠 + 分段控件）；道具（页头 + 栏位 pill + 两段长说明折叠 + 栏位未开的锁定提示）；兵营（页头 + 三条说明折叠 + 锁定样式）。

**验证了什么**：`tests/feat-shopui.test.js` 测缺口计算、与 `canAfford` 一致、折叠状态、分段控件；Playwright 中英文各截了 8 个页签、装备分类、道具页展开并滚动（页头保持在滚动区顶部），无 console 报错；`node tools/screens.js --lang en` 58 个界面均正常。

**没验证什么**：手机竖屏（<760px）只写了样式，没有截图；衣柜页（wardrobe）未改动；终极技能卡仍同时有副标题和锁定提示（略重复）；页头背景是写死的近似色（`#1f293b`），不跟随主题变化；折叠状态不写入存档。
