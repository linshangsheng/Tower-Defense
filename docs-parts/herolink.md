## 195 英雄与雇佣兵的联动（兵团羁绊）

### 目标
兵和英雄、主动技能原来各打各的。这一章让它们互相照应：带兵不只是"多几个帮手"，放技能时也会想"兵在哪"。数值保守，带兵 / 不带兵的难度大致持平。

### 规则与数值（全部在 `TD.config.merc.link`，`on=false` 一键关闭）
- 羁绊（被动）：场上每有 1 个活着的兵，英雄攻速 +3%，上限 +15%（同屏兵上限 6，所以 5 个兵就封顶）。用一条 `src: 'bond'` 的 buff 写进 `battle.buffs`，每 0.2 秒按活兵数刷新（先删旧的再推新的，不堆叠，也不会挡住 buffs 的过期清理）。战斗中英雄旁显示小徽标「兵团 +9%」（`TD.icons` 的 swords 图标，`css/herolink.css`）。
- 战鼓：兵的攻击间隔按 1 + 战鼓攻速加成 × 0.5 缩短（战鼓 +50% → 兵 +25%，Lv3 +80% → 兵 +40%）。
- 城墙修复：场上的兵同时回复 城墙回复比例 × 0.5 的最大血量（20% → 兵回 10%）。
- 冰冻领域 / 雷霆一击：本来就只作用于怪物，不会误伤兵，无需改动。
- 掩护射击：箭雨（技能）的箭命中"同车道、横向 110 以内有活着的兵"的怪，伤害 ×1.15；飘字「掩护射击」每 0.6 秒最多一次。
- 万箭天降：放箭瞬间所有兵无敌 2 秒（`battle.mercInvulUntil`，`mercHurt` 直接返回，Boss 横扫同样无效）。
- 提示：战鼓 / 修缮 / 万箭天降在兵身上有一圈光环，英雄旁飘一句短字；技能卡片与兵营说明里补了中英文联动说明（技能数据的新字段 `link`）。

### 验证了什么
- `tests/feat-herolink.test.js`：羁绊 3 个兵 +9%、6 个兵封顶 +15%、死兵后回落、buff 不堆叠、开关关闭无效；战鼓后 `mercHaste` 与兵冷却更快、结束后恢复；修缮给兵回血；掩护射击伤害比 1.15、无兵时没有；万箭天降 2 秒无敌，过后恢复受伤。`tests/game.test.js` 全部通过。
- 机器人 A/B（`/tmp/tower-saves-{1,2}-60_70.json`，第 60 / 70 关，无兵 / 带兵无联动 / 带兵有联动）：12 局/组：无兵 胜率 0%（这批存档不带兵本来就过不了 60/70 关，所以无兵不可比）；带兵无联动 胜率 50% / 城墙剩余 38%；带兵有联动 胜率 58% / 城墙剩余 54%。联动略有增益（估计 +8 个百分点，样本太小，可能是噪声），没有让难度明显变简单。

### 没验证什么
- 机器人只用 `autoMercs`，不会刻意把箭雨放在兵身边，掩护射击的实际触发率偏低或偏高没有数据；A/B 样本量小（每组 12 局），只能看趋势，不能看出 ±5% 的胜率差。
- HUD 徽标位置按画布比例估计，只在 1280×720 比例下目测过，窄屏 / 非 16:9 的位置没逐一核对；`sw.js` 的缓存清单未改（主线统一处理，需要把 `css/herolink.css` 加进去）。
- 战鼓的兵加速只做了"冷却更快"，没有给近战兵的移动加速。
