## 手机 / 触屏体验审计与自适应热区

**目标**：舞台固定 1280×720，手机上被缩到 0.44~0.55 倍（iPad Mini 0.8），舞台里 44px 的按钮到屏幕上只剩 20 多 CSS 像素，字也小于 11px。让可点击元素在**屏幕上**真实 ≥44×44、文字真实 ≥11px，且桌面端外观不变。

**审计工具**：`node tools/mobile-audit.js [--out 截图目录] [--json 结果] [--quick] [--list] [--baseline]`。用 Playwright 真机预设 iPhone 13 / iPhone SE / Pixel 5 / iPad Mini，竖屏 + 横屏，逐屏（标题、地图、商店 8 个页签含兵营、设置、战斗 HUD 含雇佣兵栏、结算）截图；用 `getBoundingClientRect`（已含缩放与 90° 旋转）量每个可点击元素的屏幕尺寸，用"计算字号 × 舞台缩放 × 沿途 zoom"算文字实际字号，并检查溢出视口、雇佣兵栏 / 技能栏 / 道具栏 / 控制栏 / 顶栏互相遮挡；再用真实触摸 tap 验证旋转下的光球拾取、点怪集火、点城墙修补、集结令（点按钮 + 点车道）。`--baseline` 屏蔽本次新增的 `css/mobileui.css` 与 `src/ui/mobileui.js`，用来量"修复前"。

**规则**：
- `src/core/touch.js`（纯函数 `TD.touch`）：`isCompact(scale, coarse)`：缩放 < 0.7，或触屏设备（`pointer: coarse`）缩放 < 0.9；`stageMin(scale)` = 44 / scale；`fontFloor`、`boostFor`、`meetsTarget` 等换算。
- `main.js` 的 `fit()`：按上面判断给 `#ui` 加 / 去 `compact`，并设置 CSS 变量 `--hit`（屏幕 44px 对应的舞台像素）、`--fmin`。
- `css/mobileui.css`：仅 `#ui.compact` 下生效。按钮、页签、配装格子、地图节点、下拉框、复选框、技能 / 道具 / 雇佣兵按钮 `min-width/min-height: var(--hit)`；商店页签列加宽；战斗底栏随热区增高，雇佣兵栏相应上移，不压技能栏。选择器加了 `:not(#_)` 抬高优先级，盖过已有的 `#ui.large-text` 规则。
- `src/ui/mobileui.js`：紧凑模式下，把"屏幕上实际字号 < 11px"的文字元素的字号抬到 11 屏幕像素（单个元素最多放大 2.7 倍），界面节点增减时（开关弹窗、换页签、翻译器改字）重扫一遍（不盯文字变化，战斗每帧刷数字不会触发）；离开紧凑模式时还原。

**验证结果**（`tools/mobile-audit.js` 全量：4 台设备 × 竖 / 横 × 12 个界面，共 96 屏；"不达标"按元素实例计数）：

| | 修复前 | 修复后 |
|---|---|---|
| 可点击元素 <44×44 屏幕 px | 1838（共测 1902 个） | 0（共测 1599 个） |
| 文字实际字号 <11px（按元素类 + 字号去重） | 1548 | 0 |
| 超出视口的元素 | 0 | 0 |
| 雇佣兵栏 / 技能栏等互相遮挡 | 0 | 0 |
| 旋转下点击（光球 / 集火 / 修补 / 集结令，32 项） | 32 通过 | 32 通过 |

修复后"共测"数量变少，是因为放大后部分按钮被移进了可滚动区域的视口之外（只统计当前可见且未被遮挡的）。`tests/feat-mobileui.test.js` 覆盖 `TD.touch` 的纯函数与旋转点击坐标往返。桌面 1280×720 下 `compact` 不出现、没有被改过的字号、无报错。

**没验证什么（诚实）**：
- 没在真机上测，只在 Playwright 的设备模拟（Chromium，软件渲染，deviceScaleFactor 固定为 1）里测；iOS Safari 对 CSS `zoom`、`:not(#_)` 等的表现没验证。
- 放大后部分界面变得拥挤（商店配装页、装备页要多滚动，一些说明文字换行更多），我只看了 iPhone 13 / SE 的几张截图，没有逐屏做美术上的精修；横屏 / Pixel 5 / iPad 只看了数字没逐张看图。
- 审计只覆盖主要界面；剧情对话、小镇、成就、图鉴、补给卡、暂停菜单、弹窗确认没进脚本。战斗截图里的城墙血量是接近真实的 12000，其余数值是测试存档的，不代表真实进度。
- 字号单个元素最多放大 2.7 倍封顶，极小屏上个别地方可能被封顶而未达 11px，本次审计中为 0，但取决于当时界面内容。
- 没新增玩家可见中文文字，所以没有 i18n 增补。`sw.js` 的缓存文件清单由主线统一处理，新增文件 `src/core/touch.js`、`src/ui/mobileui.js`、`css/mobileui.css` 需要登记。
