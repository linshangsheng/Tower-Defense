## 无尽模式 / 每日挑战里的雇佣兵（mercmodes）

**目标**：无尽、每日这类 `levelDef` 战斗里带兵不吃亏，并让玩家看得到兵干了什么。

**规则与数值（均为估计值）**
- 无尽每清一波（第 i 波开始时，已清 i 波）带兵者额外得军饷：`min(80, round(10 + 2.5 × i))`（`C.merc.endlessWaveFunds = [10, 2.5, 80]`，`TD.modes.endlessWaveFunds`）。不带兵、普通关卡、每日挑战都不送。
- 新系数 `C.merc.endlessMerc = 0.6`：无尽里"带兵后怪物血量 +55% / 攻击 +30%"乘以 0.6（实际约 +33% / +18%）。普通关卡与每日挑战仍为 1。
- 结算（无尽与每日共用 `showModeResult`）在有雇兵时追加一行"雇佣兵：雇佣 / 阵亡 / 击杀"，数据来自已有的 `mercDeployed / mercDeaths / mercKills`。

**验证了什么**
- 机器人（前三个兵种、通关 25 关、`bot.shop`、20000 铜）打无尽，5 个种子，时间上限 2400 秒，平均清波：不带兵 56.6；带兵无补贴且系数 1：43.6；加每波军饷：50.2；再加系数 0.6：56.0；系数 0.3：59.6。选 0.6 使带兵与不带兵大致持平。
- `tests/feat-mercmodes.test.js`：军饷公式与封顶、带兵 / 不带兵 / 普通关卡、系数缩放、结算字段存在。

**没验证什么**
- 机器人多数局被 2400 秒上限截断（约 59–62 波），区分度有限，种子也只有 5 个；只测了通关 25 关一档，没测更高进度。
- 没有用真人手动操作兵的数据；没有 Playwright 截图确认结算那一行的版式。
- 每日挑战只确认字段存在，没单独调数值。
