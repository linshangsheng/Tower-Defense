## 冲阵：大块头撞飞前排兵

### 目标
带兵时，大块头怪物撞上兵不再只是停下来对砍，而是把贴身的前排兵撞飞并短暂眩晕，让"血厚的大怪"在兵线前有存在感，也逼玩家用英雄火力去处理它们，而不是只靠兵堆。

### 规则与数值
- 数据：怪物定义里的 `trample = { every, kick, stun }`（冷却秒数、击退距离、眩晕秒数）。没有放进 `trait`（一只怪只有一个 trait，雪怪 / 战车已有咆哮 / 撞墙），而是独立字段，由 `traits.js` 的 `trampleMercs(m, blk)` 处理；回声怪靠 `echo()` 继承基础怪的字段。
- 6 种怪（均为非 Boss 地面近战）：树桩怪（6s / 55 / 0.9s）、雪怪（5.5s / 60 / 0.9s）、钢雪怪（5.5s / 70 / 1.0s）、熔岩傀儡（6s / 70 / 1.1s）、熔铁傀儡（6s / 80 / 1.2s）、铁战车（4s / 90 / 0.8s）。
- 触发：怪被兵拦住（`mercBlockerFor`）且冷却好、自己没被冻 / 晕时，同车道、贴身（接触距离 + 体型一半 + `trampleReach` 24）的所有兵被击退 `kick`（不会越过城墙前 `wallX+40`）并眩晕；这一帧怪不打兵，撞完再恢复。撞不到兵（兵在免疫期）不消耗冷却。
- 眩晕中的兵：不走、不打、牧师不治疗；仍然是怪的目标。
- 盾卫（`taunt` 且 `reduce`）眩晕时间 ×0.5（`C.merc.trampleGuard`），击退距离不变。
- 防锁死：眩晕结束后 1.5 秒（`trampleGrace`）免疫，几只大怪不会把同一个兵连环锁住。
- 视觉：冲击环两层、尘土、轻微震屏、"冲阵！"字样（`fx` 过多时省略）；被撞的兵从原位置滑到新位置并腾空一小段（0.28s）；眩晕时血条上方转三颗星（`TD.icons` 的 star，没用 emoji）。
- 图鉴说明（6 只怪 + 盾卫）已更新，英文在 `i18n-add/trample.json`。

### 验证了什么
- `tests/feat-trample.test.js`：数据范围（眩晕 0.8–1.2s）、击退距离 = kick、眩晕时长、眩晕期间兵不动不打、冷却、盾卫眩晕减半且击退不变、不撞进城墙、只撞贴身前排、免疫窗口、冻住的怪不冲、无兵不触发。
- `tests/game.test.js` 全部通过。
- Playwright 截图：冲击环、"冲阵！"、星星、兵被撞开的位置都正常显示，无 console 报错。
- A/B（用 `/tmp/tower-saves-1-60_70.json` 的存档，关卡 12/20/25/30/35/40/45/50/55/60/64/68 × 4 个种子，自动补给 + 自动出兵）：改动前：不带兵 33/48 胜、城墙剩余均值 59.5%，带兵 32/48、59.7%；改动后：不带兵 33/48、59.5%，带兵 33/48、60.5%（每局平均撞 1.9 次）。带兵与不带兵持平，未再调数值；样本小（48 局），差异在噪声内。

### 没验证什么
- 只用机器人做了 A/B，没有真人手感测试；击退 / 眩晕 / 冷却数值是估计值，未做网格调参。
- 手机竖屏下星星和字样的大小没有单独看。
- 英文界面下"Trample!"字样的排版没有截图确认。
- 没有测试多只大怪同车道叠加、集结令换道与眩晕同时发生的极端情形（逻辑上换道照常，眩晕不阻止换道移动）。
