## 雇佣兵专属音效（mercsfx）

### 目标
雇佣兵原先复用 skill / hit / shoot / pop / streak / drum，听不出是谁在打。现在每个兵种有自己的出手、受击、阵亡、到场声，另有晋升、集结令、骑士冲锋、牧师治疗的专属声。全部是 `src/render/audio.js` 里的合成音，不引入音频文件。

### 规则与数值
- 命名：`merc_<兵种>_<atk|hurt|die|deploy>`（兵种 = swordsman / guard / archer / mage / cleric / knight），另有 `merc_charge`、`merc_heal`、`merc_rank`、`merc_rally`。共 28 个。
- 出手：剑士 = 金属噪声 + 清脆泛音；盾卫 = 低频闷击；弓手 = 弓弦升调 + 高频箭羽噪声；法师 = 升调咒音；骑士 = 低沉枪刺，冲锋另有马蹄三连 + 重击；牧师 = 大三和弦琶音（治疗时）。
- 受击按材质：剑士（金属脆响）、盾卫（木盾闷响）、骑士（铁甲）、弓手 / 法师 / 牧师（布衣，较轻的音）。
- 单个声部增益 0.04–0.14（估计值，偏低，晋升 / 集结等少见的事件取上沿）；英雄的 crit 为 0.22，所以兵的声音不压英雄。
- 限流 `MIN_GAP`：出手 0.12s、受击 0.18s、阵亡 0.15s、到场 0.2s、冲锋 0.3s、治疗 0.4s、晋升 0.3s、集结 1s。
- `src/game/mercs.js` 新增 `mercHurt` 事件（`{u}`），每个兵至少隔 0.25s 才发一次（Boss 横扫是每帧调用）；`main.js` 用 `TD.audio.mercSound(kind, e.u.type)` 按 `u.type` 选声音，未知兵种回退到剑士。

### 验证了什么
- `tests/feat-mercsfx.test.js`：所有新声音名已注册；`MIN_GAP` 覆盖全部高频兵音效；`main.js` 里九个事件都已绑定；用假 AudioContext 检查每个兵音效的最大声部增益在 0.04–0.14；`mercHurt` 事件与限频字段存在。
- 用 Chromium 的 OfflineAudioContext 离线渲染全部 28 个音（含主 0.35 增益），检查：无 NaN、峰值 0.02–0.074（对照原 shoot 0.026 / hit 0.014 / skill 0.068 / crit 0.096）、时长 36–540ms、过零率估计的主频与设计一致（盾卫 80–260Hz，弓手箭羽 > 3kHz 等）。脚本在 scratchpad 的 `mercsfx-wave.js`。
- `tests/game.test.js` 305 项（含新测试）全部通过。

### 没验证什么
- **未经人耳验证**：音色好不好听、各兵种能否听出区别、和背景音乐 / 英雄声音的实际混音平衡，都只做了波形 / 频率 / 增益层面的自检，没有人耳确认。
- 6 个兵同时开打的真实听感（限流间隔是估计值）、手机扬声器上的低频（盾卫 / 骑士 80–150Hz）是否听得到，均未验证。
- 没有跑完整局的浏览器实机播放。
