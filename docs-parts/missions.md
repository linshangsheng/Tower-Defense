## 雇佣兵关卡任务

**目标**：让雇佣兵有"玩法目标"，给关卡任务（可选星外挑战）加 7 个兵相关变体。

**规则与数值**（门槛均为估计值）
- 同生共死：雇 ≥3 个、0 阵亡；精兵简政：雇 ≥3 个、同屏峰值 ≤3；铜墙铁卫：盾卫挡下怪物攻击 ≥20 次；百战老兵：≥2 个兵晋升到 3 级（vetMax）；专精一道：只带 1 个兵种、雇 ≥4 个；各守其路：雇 ≥3 个、集结令 0 次；兵锋所向：兵击杀 ≥30% 且雇 ≥3 个。
- 统计字段在 `src/game/mercs.js` 的 `mercSummary()`（mercBlocks / mercPeak / mercMaxRanks / mercRallies / mercCarried），`battle.finish()` 只加一行并入结果。"挡住"=盾卫被非 Boss 怪的一次攻击命中（Boss 横扫不算）。
- 分配：`missionFor(n)` 拿不到存档，所以不判断玩家有没有兵。规则：n≥30（剑士/盾卫/弓手/法师已解锁）、n%4==2、普通类型关（normal/raid/rush/armored/dark/union，非塔、非 Boss/小 Boss/精英）。共 34 关，7 种轮换。没带兵时判定一律不通过（任务照常显示，是可选挑战）。
- 奖励沿用现有规则（普通关 200 铜）。

**验证了什么**：每个任务的判定（含边界、没带兵、除零）、分配规则（7 种都出现、第 30 关前和特殊关无兵任务）、战斗结果字段，见 `tests/feat-missions.test.js`；`tests/game.test.js` 全过。用机器人（自动雇兵、一个种子推到 66 关）看了 8 个兵任务关：机器人完成 3/8，且几乎每关阵亡 12–39 个兵。

**没验证什么**：门槛没有按真人玩家调；机器人兵种占比只有 3%–17%，30% 的击杀占比对机器人偏难，真人专门玩兵可能可行，但属估计值，只跑了 1 个种子；界面上任务文字的实际排版没截图看；没带兵的玩家看到兵任务只能忽略（"missionAll"成就因此要求带兵打这些关）。
