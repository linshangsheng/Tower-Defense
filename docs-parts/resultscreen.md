## 关卡结算页重做（苹果 HIG 取向）

### 目标
旧结算页：发光大字标题、奖励行密、一长串彩色通知、底部按钮压在内容上。改成清晰的层级，失败页要有建设性。

### 规则与布局
- 单列、宽 600px（窄屏自适应），从上到下：大结果（胜利：三颗星用 `TD.icons` 的 star 图标逐颗弹出；失败：盾牌徽标 + “这关还需要准备”，文案不自责）→ 本场数据 4 张等宽卡（用时 / 击杀 / 连击 / 城墙剩余；失败时第 4 张换成“守到波数”，因为城墙必为 0）→ 奖励（铜币合计滚动计数，明细行降为 13px 次要文字）→ 最划算的升级 → 通知 → 战斗报告（折叠；失败时默认展开）。
- 失败时“推荐强化”提到最前面，做成强调色底的醒目卡片。
- 通知按优先级排序（成就 > 解锁 > 援军 > 其他 > 补给），最多展开 3 条，其余折叠为“还有 N 条”（可展开 / 收起）；只多 1 条时直接展开。纯函数在 `src/ui/result-helpers.js`（`TD.resultView`），Node 可加载。
- 底部操作栏沿用 `ds.css` 的粘底毛玻璃，边到边；只有一个主按钮（有下一关 = “下一关”，否则 = “再来一次”）；新手失败时“去商店”按钮保留轻微晃动提示但不再是第二个主按钮。
- 动效：星星 0.5s 弹出（间隔 0.22s），铜币数字 0.5–1.1s 先快后慢滚动；设置里开“减少动效”（或系统 prefers-reduced-motion）时星星直接显示、数字直接给最终值。
- 所有原有信息仍在：成就、解锁、补给、各类通知、雇佣兵出战 / 阵亡、精英、宝箱怪、光球、最高连击（战斗报告里的胶囊标签）。表情符号换成 `TD.icons` 线性图标。
- 战斗报告外观（`UI.reportEl`）同步改了：数据胶囊带图标，也用于挑战模式结算。
- 改动文件：`src/ui/ui.js`（showResult / quickUpgradeEl 标题）、`src/ui/ui-collection.js`（reportEl）、`src/ui/result-helpers.js`（新）、`css/resultscreen.css`（新）、`index.html`、`tools/load.js`（各一行）。

### 验证了什么
- `node --test tests/game.test.js tests/feat-resultscreen.test.js`：311 通过 0 失败（含折叠、数据卡、滚动计数、星星、奖励明细的单测，以及“不用 `??`”的现有兼容性检查）。
- Playwright 1280×720 中 / 英文的胜利与失败页截图：无溢出（scrollWidth = clientWidth）、无 console 报错、底部栏只有 1 个主按钮；844×390 横屏和 390×844 竖屏（游戏自带的旋转布局）可用。

### 没验证什么
- 真机手机；系统“大字”模式、其他 14 种语言下的换行。
- 动画只在截图时看到最终状态，没有逐帧检查；减少动效开关路径只读代码确认，没有截图。
- 英文截图里“成就名 / 解锁说明”是我测试里编的中文，没有词典条目，所以显示半翻译，不是界面 bug。
- 竖屏旋转模式下弹窗整体被缩得较小，那是游戏原有的旋转缩放，没有改。
- `sw.js` 的预缓存清单没有登记新文件（规范不让改），需主线加入 `css/resultscreen.css` 和 `src/ui/result-helpers.js`。
