## 兵种天赋（养成深度）

**目标**：雇佣兵原先只有"花铜币升级，血量和伤害 +12%/级"一条养成线。给每个兵种在 3 / 6 / 9 级各加一次"二选一"天赋，让同一个兵种有不同的打法，并给铜币一个新去处。

**规则**
- 每个兵种 3 档 × 2 选 1（数据：`src/data/mercTalents.js`；`C.merc.talentLevels = [3, 6, 9]`）。等级不到的档位显示锁定，选择不生效。
- 第一次选免费；改选（洗点）按档位收铜币：`respecBase(60) × 档位`，即 60 / 120 / 180。
- 存档 `save.mercTalent = { 兵种id: [档1, 档2, 档3] }`，每项 0 / 1 / null；`P.newSave` 默认 `{}`，`P.migrate` 丢掉未知兵种、把非 0/1 的值改为 null、补齐到 3 项。没选的档位没有效果（不会替玩家默认选）。
- 引擎：`deployMerc` 把天赋合并成 `u.fx`，折算到血量、伤害、攻速（`u.every`）、爆炸范围（`u.aoe`）；其余在出手（`mercAttack` / `mercHit`）、受伤（`mercHurt`）、治疗、每帧回血里读取。
- 天赋一览（24 个）：剑士 连斩 攻速+20% / 破甲 对护甲≥30 的怪+30%；嗜血 击杀回 15% / 重击 每 4 击 1.8 倍；剑旋 顺劈 50% / 不死 每场一次保留 30% 血。盾卫 铁壁 减伤 +10% / 复仇 反弹 20%；厚甲 血+20% / 加固盾墙 盾墙再 −15%；不动如山 半血以下再减 15% / 战地自愈 每秒 2%。弓手 穿云 多射穿 1 个 / 速射 攻速+25%；精准 25% 暴击×2 / 空中猎手 对飞行+50%；毒箭 灼烧 / 坚韧 血+40%。法师 烈焰 灼烧 / 寒霜 减速 40%；扩爆 范围+25% / 聚能 伤害+20%；速咏 攻速+25% / 陨星 每 3 发 1.9 倍。牧师 庇护 目标 3 秒减伤 20% / 复苏 治疗+30%；群疗 第二伤员 50% / 速祷 间隔 −20%；城墙祝福 城墙治疗×3 / 战地急救 低血目标 1.8 倍。骑士 践踏 冲锋溅射 60% / 不屈 冲锋后回 20% 血；铁甲 减伤 15% / 长枪 伤害+15%；复冲 每 10 秒再冲锋 / 精锐 血+25% 伤+10%。
- 与原设计的出入：盾卫"铁壁 35%→45%"、复仇反伤从 10% 提到 20%（10% 太弱，选它几乎等于白选）；骑士"践踏"原为"范围 +60%"，但冲锋本来没有范围，改为"冲锋溅射 60%"。
- 界面：兵营卡片下方"天赋"区，三行二选一按钮（≥44pt 热区、图标用 `TD.icons`），选中态强调色淡底，未解锁显示锁和所需等级，改选显示铜币价格。样式在 `css/talents.css`。

**验证了什么**
- `tests/feat-talents.test.js`（10 条）：数据完整、解锁时机、选择生效（攻速 / 血量 / 减伤 / 范围 / 反伤 / 不死 / 灼烧 / 减速 / 穿透 / 治疗 / 冲锋回血 / 复冲）、洗点扣费、存档迁移与坏数据。`tests/game.test.js` 全部仍通过。
- 机器人 A/B（机器人推进存档，雇佣兵升到 10 级，每个格子 4–6 个种子）：第 20 关前排三兵，无天赋城墙剩余 40%，全选第一条 48%，全选第二条 57%，混选 46–52%；第 14 / 32 / 65 关带兵胜率 100%，城墙剩余无天赋 92%（65 关）→ 全选第一条 97% / 第二条 94% / 混选 96%。结论：天赋让满级兵略强（城墙剩余 +5–17 个百分点），两条路线互有高低，没有一条碾压；带兵仍然不比不带兵难。
- Playwright 截图检查了兵营页布局（桌面宽度），无 console 报错。

**没验证什么**
- 机器人 A/B 样本很小（4–6 个种子），第 50 关的存档机器人本身过不了，没有信息；没跑完整战役。胜率差在这样的样本里是噪声量级，只能说"没有明显失衡"，数值全部是估计值。
- 机器人默认不会选天赋，A/B 里是直接写存档；真实玩家的选择分布没有数据。
- 手机竖屏只看了强制横屏的提示截图，没有在真机上看天赋区；英文版天赋文字依赖 `i18n-add/talents.json` 合并后才有整句翻译，界面里英文长度没有逐条检查。
- 复仇 / 不死 / 穿云等在真实战斗画面里的表现（特效、飘字）没有做，只有数值生效，没有专门的视觉反馈。
