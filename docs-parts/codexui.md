## 图鉴与成就页升级（codexui）

### 目标
把怪物图鉴和成就页按苹果 HIG 的取向重做展示层：能搜、能筛、信息有层级、进度一目了然。**只改展示，数据和结算逻辑不变。**

### 做了什么
- **图鉴**：顶部 iOS 风格圆角搜索栏（44pt 高，聚焦时强调色描边，带清除按钮，Esc 清空）；其下是"类型"分段控件（全部 / 飞行 / 远程 / 治疗 / 重甲 / 盾牌 / 隐身 / 自爆 / 分裂 / Boss），由 `D.monsterTags` 生成，只保留"已遇见的怪里至少有 2 只"的类型，最多 6 个；章节页签改成可横向滚动的圆角 chips（两端渐隐、吸附居中）。
- **搜索规则**：按名字、说明、标签匹配，同时匹配中文原文和当前语言译文（英文界面里搜 `fly`、中文里搜 `飞` 都行），忽略大小写和多余空格。有搜索词或类型筛选时跨章节，章节 chips 变灰；否则只看当前章节。**未遇见的怪物不参与搜索**，防止靠搜索"透视"名字。
- **怪物卡片**：统一高度 148px、72px 固定图标区、技能标签用 pill（单行不换行）、说明最多 4 行；未解锁显示剪影 + "？？？"；已击败数右上角大号 tabular 数字。
- **成就页**：顶部 SVG 环形总完成度（百分比居中）；成就按 进度类 / 战斗类 / 收集类 / 雇佣兵类 分四组，每组一个可折叠区（头部显示 已完成/总数，折叠状态本次游戏会话内记住）；每个成就卡片有图标、进度条、`当前 / 目标`（如累计雇佣 30 个 → `17 / 30`）；没有量化条件的只显示"已完成 / 未完成"。已完成用强调色，未完成保持中性。
- **空状态**：搜索无结果显示放大镜图标 + 标题 + 提示 + "清除筛选"按钮。
- 纯函数抽到 `src/game/codex.js`（`TD.codex`：`filterBestiary` / `typeSegments` / `groupAchievements` / `achProgress` / `overall` / `ringOffset`），Node 里可加载测试。
- 有量化进度的成就共 40 个（累计类直接读 `save.stats`；章节通关类用"已通关关卡数 / 目标关数"；星星/王冠/任务/妖塔/无尽/兵种等级等读存档对应字段）；分组和进度表按成就 id 写死在 `codex.js`，**新增成就需要同步加到表里**，否则会落进"其他类"、且只显示完成态（测试会检查现有成就都已分组）。

`src/game/codex.js`（新）、`css/codexui.css`（新）、`src/ui/ui-collection.js`（重写 `showBestiary` 和成就页主体，守城档案不动）、`index.html` / `tools/load.js` 各加登记行、`i18n-add/codexui.json`、`tests/feat-codexui.test.js`。

### 验证了什么
- `node --test tests/game.test.js tests/feat-codexui.test.js`：312 通过 / 0 失败（本任务新增 12 个）。
- Playwright 中英文各截图（图鉴第 1 / 7 章、搜索命中、搜索无结果、类型筛选、成就页、折叠、守城档案），无 console / pageerror 报错。
- 纯函数测试覆盖：章节过滤、中英文搜索、未解锁不被搜出、Boss 类型匹配、分组完整无重复无遗漏、进度封顶不溢出、已完成进度为满、空存档不抛错、环形偏移夹取。

### 没验证什么
- 窄屏（手机宽度）只写了 640px 以下单列的样式，**没有实际截图确认**。
- 没在真机 Safari / 触屏上测试横向滚动 chips 与吸附手感。
- 除英语外的语言不存在；英文译文是我写的自然文案，但未经母语者审阅。
- 搜索输入的 IME（中文拼音输入法）组合输入过程中会逐字过滤，未专门处理 `compositionstart`。
- 折叠状态不写入存档（刷新页面后重置），这是有意的。
