# 翻译说明（给翻译者 / Translation guide）

游戏《最后的堡垒》(The Last Bastion) 是一款儿童绘本风的塔防游戏：一个小卫兵 Kael 和同伴们守卫城墙，打败"墨水"污染的怪物。
`i18n/keys.json` 是所有简体中文原文（1852 条，按顺序），译文放在 `i18n/parts/<语言代码>-<段>.txt`。

## 格式
- 分 4 段（`node tools/i18n-part.js` 看范围，`node tools/i18n-part.js N` 打印第 N 段的 `下标<TAB>原文`）。
- 译文文件 `i18n/parts/<code>-N.txt`：每行 `下标<TAB>译文`，**每个下标一行**，原文里的换行在译文里写成字面的 `\n`（反斜杠加 n）。
- 检查：`node tools/i18n-merge.js <code> --part N`（检查缺漏、占位符、换行数、不该有的汉字）。全部段完成后 `node tools/i18n-merge.js <code>`。

## 规则
1. **占位符**：`{0}` `{1}` … 是程序填进去的数字或名字，必须原样保留（顺序可以按目标语言语法调整），个数一致。
2. 条目有时只是**句子片段**（以标点开头或结尾，如 `，可同时戴 3 件`、`· 补给中`）：翻成能拼接到前后文的片段，保留开头/结尾的标点语义和前后空格习惯。
3. 保留不译的名字：Kael、Lyra、Atlas、Nova、Rowan（主角们）；数字、%、×、+、−、Lv、HP、DPS 等符号照搬。
4. **UI 文字要短**：按钮、标签、标题尽量不比原文长太多（手机竖屏），用目标语言游戏里常用的简短说法。
5. 术语统一（同一个词全程用同一个译法）：铜币=copper coins（基础货币）、金币=gold coins、钻石=diamonds、墨水=Ink、堡垒/城墙=bastion/wall、九层妖塔=Nine-Floor Demon Tower、波=wave、关=level/stage、装备/道具/英雄/技能/天赋/套装 等用各语言游戏里的惯用词。
6. 语气：轻松友好的儿童冒险故事。剧情对白（以"……"开头的台词等）要自然口语化。
7. 标点：写目标语言的正常标点（拉丁/西里尔/韩/泰用半角标点；日语、繁体中文用全角标点）。
8. 不要留下任何汉字（日语、繁体中文除外）；不要改动 `{n}` 之外的 HTML/符号（如 ★ ✓ ⚔ 🪙 💎）。
9. 各语言要求：es=拉美通用西语；pt-BR=巴西葡语；pt-PT=欧洲葡语（用 tu/você 习惯、-ção 之外的欧洲拼写，如 "ecrã"、"telemóvel"）；zh-Hant=台湾繁体用语（如"伺服器"、"預設"、"檔案"）；ja=です・ます体、漢字かな交じり；ko=해요체/합니다체统一；de=Sie 或不称呼均可，保持简洁；fr=vous 或不称呼；ru/pl/tr/it/id/vi/th 用该语言游戏界面惯用语。
