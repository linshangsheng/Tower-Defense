## 守住城墙，放出技能，屠龙。

**《城头射手》（Archer on the Wall）**是一款横版自动战斗塔防：小卫兵站在城墙上自动射箭，怪物沿车道从右边走来。**战前配装、战斗中放技能 / 用道具 / 提前召唤下一波，由你决定**。城墙血量归零就失败。

免费、网页直接玩，不用安装、不用注册。存档保存在浏览器里（设置里可以导出 / 导入）。

![Boss 战](screenshots/01-dragon-boss.png)

### 游戏内容

- **20 章 200 关**：翠绿草原、黄金沙漠、迷雾沼泽、冰霜雪原、熔岩裂隙、云端王国、珊瑚海湾、月影古堡、赤铁熔炉、虚空天域……通关第 100 关后开放「深渊回响」十章，把前面的敌人换成更强的混搭版本。
- **14 个 Boss + 6 个回声 Boss**，各有阶段和需要摸清的机制：打断蓄力、抓输出窗口、先拆护身。最后的 **焚天巨龙有两条命**：喷火、冲撞城墙、召来雷击（**麻痹主角 2 秒**）和寒冰（**冻住主角 3 秒**）；倒下之后会化作黑龙，各项属性再翻三倍。
- **5 位英雄**、**25 把武器**（绿 / 蓝 / 紫 / 红 / 金五个品质，高品质一次多箭、穿透、点燃）、**10 个主动技能**、**10 个被动技能**、**180 件装备**（六个部位）、**45 种消耗品**、城墙升级、**10 位角色的衣柜**。
- **九层妖塔**、**无尽模式**、**每日挑战**、怪物图鉴、成就、每关一个可选任务。
- **三档难度**（轻松 / 标准 / 挑战，挑战通关得王冠）；连续失败会有「援军鼓舞」。
- **光影手绘画面**：每章有自己的光源、雾、光束和漂浮光点；城墙越打越破；每个技能都有自己的动画。电脑吃力时自动降低特效（设置 → 画质）。
- **交响乐配乐**：23 首曲子，随战斗紧张度分层。
- **17 种语言**（译文由 AI 生成，未经母语者审校，欢迎纠错）。

### 操作

| 操作 | 方式 |
|---|---|
| 释放主动技能 1 / 2 / 3 | 点技能按钮，或按 **1 / 2 / 3** |
| 需要选车道的技能（冰冻领域、烈焰之墙、炸弹……） | 点技能，再点一条车道；右键或 **Esc** 取消 |
| 使用道具 | **Q W E R Z X C**（或点击） |
| 暂停 | **空格** |
| 切换速度 | **F**（通关第 10 关后有 3 倍速） |
| 提前召唤下一波（剩余倒计时变成铜币） | **N** |
| 切换目标优先级 | **T** |

城墙剩余 ≥ 50 % 得 2 星，≥ 80 % 得 3 星。钻石只能在九层妖塔里获得。
