# 最后的堡垒

2D 横版自动战斗塔防（网页原型）。小卫兵Kael站在城墙上自动射击，你负责战前配装、战斗中释放技能和道具，守住城墙。

## 怎么玩

直接用浏览器打开 `index.html` 就能玩，不需要安装任何东西。

- 战斗中：`1` `2` `3` 释放主动技能，`Q` `W` `E` 使用道具，`空格` 暂停，`F` 切换速度（通关第 10 关后有 3 倍速），`N` 提前召唤下一波，`T` 切换目标优先级。
- 需要选车道的技能（冰冻领域、小炸弹、冰冻瓶）：点技能后再点一条车道，右键或 `Esc` 取消。
- 存档保存在浏览器本地，"设置"里可以导出 / 导入。
- 部署到 https 网站（如 GitHub Pages）后，手机 / 平板可以"添加到主屏幕"，断网也能玩。

## 当前内容（原型 v0.55，七章 70 关）

- **七章 70 关**：翠绿草原、黄金沙漠、迷雾沼泽、冰霜雪原、熔岩裂隙（最终 Boss 墨墨与结局演出），以及通关后的第六章「云端王国」、第七章「珊瑚海湾」（会互相保护的海湾怪物：缩壳、护卫、跳跃、尖刺、泡泡）。
- **14 个 Boss**，各有阶段与可以"打断"、"抓窗口"、"先拆护身"的机制；第 49 关精英挑战小 Boss 两两出场。
- **五位英雄**：Kael（均衡），以及陆续加入的Atlas（第 10 关，守护城墙）、妹妹Lyra（第 20 关，攻速快、铃声眩晕小怪）、Nova（第 30 关，暗夜不减射程、放萤火虫）、Rowan（第 40 关，重箭破甲、击退）。
- **15 把武器**（绿 / 蓝 / 紫 / 红 / 金五个品质，越高越强越贵；可升级、进阶）、5 个主动技能（3 级）、4 个被动技能、**24 件装备**（头盔、披风、箭袋、饰品；多数带特长效果，两套套装，随章节上架）、城墙升级、**16 种消耗品**（冰冻全体、洪水、陨石雨、时间静止……越强越贵）、四种货币（钻石暂时无法获得）与汇兑所；装备可以半价出售；城墙按血量逐档破损；战场补给每关两次三选一。
- **难度**：轻松 / 标准 / 挑战；连续失败会获得"援军鼓舞"；挑战难度通关得 👑 王冠。
- **守城日记**：章节开场、Boss 战前战后对话，日记本可重看；**王国小镇**：打败的 Boss 搬来当邻居。
- **关卡任务**（每关一个可选任务）、成就、怪物图鉴、**Kael的衣柜**（10 套外观）。
- **战斗报告**：伤害来源、被护甲挡掉的比例、城墙伤害来源和针对性建议。
- 无尽模式、每日挑战、连击提示、休息提醒、手机横屏可玩。
- **光影手绘画面**（v0.46）：每章有自己的主光源、远景、雾、光束和漂浮光点，角色有明暗和轮廓光，界面是半透明的深色玻璃质感（v0.47 起所有弹窗统一）。v0.48 起角色是修长的光影生灵；v0.49 新增启动动画与徽章 Logo，暗夜关是真正的黑夜（只有火把和箭光照得到）。v0.52 起角色加上毛发、鳞片、甲片、发光纹路等细节，技能特效重做（法阵、分叉闪电、火球冲击波、冰晶车道、治疗光柱）。

## 开发

需要 Node.js 18 以上（只用于测试和数值模拟，游戏本身不依赖 Node）。

```bash
npm test        # 核心逻辑单元测试
npm run sim     # 强机器人模拟，检验各章的验收目标（--campaign / --hard / --hero ding）
node tools/casual.js --seeds 6        # 休闲玩家模拟，估计真人难度（--easy / --no-rally）
node tools/tune.js 51 60 --only 55,60 # 自动平衡：按关卡类型的目标难度调整怪物数量倍率
npm run smoke   # 浏览器冒烟测试（需要 Playwright），截图输出到 screenshots/
npm run screens # 全界面检查：逐一打开 43 个界面（node tools/screens.js 目录 可截图）
npm run perf    # 渲染性能（真实帧循环下的帧间隔）
npm run pwa     # 离线功能检查（本地服务器 + 断网刷新）
node tools/icons.js                   # 重新生成 PWA 图标
```

改动战斗逻辑结构（不改数值）时，用 `node tools/sim.js --seeds 2 --campaign --verbose` 在改动前后各跑一次，输出必须逐行一致。更新游戏版本时记得同时改 `sw.js` 里的 `VERSION`，否则已安装的玩家会继续用旧缓存。

目录结构：

| 目录 | 内容 |
|---|---|
| `src/data/` | 数值与关卡数据（与设计书第 18 章对应） |
| `src/game/` | 战斗逻辑、成长与商店、存档、模拟机器人（不依赖画面，可在 Node 中运行） |
| `src/render/` | Canvas 绘制、特效、合成音效 |
| `src/ui/` | DOM 界面：标题、地图、商店、战斗 HUD、结算 |
| `tools/` | 数值模拟、截图与冒烟测试脚本 |
| `tests/` | 单元测试 |
